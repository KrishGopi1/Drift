# Roadmap

What's done, what's next, and where Drift might go. No dates: this is a spare-time project, and things ship when
they're ready and tested.

Want to help with something here? Look for a matching issue or start a thread in
[Discussions → Ideas](https://github.com/KrishGopi1/Drift/discussions/categories/ideas).

## Current

- [x] Offline analysis engine (deterministic, versioned, cited parameters)
- [x] Health Connect integration
- [x] Sleep as Android import (Health Connect, CSV backup, tracking broadcast)
- [x] On-device phone sleep detection
- [x] Sleep history and drag-to-edit nights
- [x] Sleep debt
- [x] Sleep need estimation
- [x] Circadian estimation and melatonin window
- [x] Energy curve and energy potential
- [x] Sleep Regularity Index and chronotype
- [x] Home-screen widget
- [x] Encrypted local storage and backups

## Next

- [ ] Make the energy graph more visible on the Sleep home screen
- [ ] Widget improvements (sizes, more useful content, better accessibility)
- [ ] Improve phone-based sleep detection
- [ ] Improve wearable integrations (more origin packages mapped to quality tiers)
- [ ] More robust shift-worker handling
- [ ] Better uncertainty reporting
- [ ] More validation against real-world data (replayed exports, check-ins)
- [ ] Translations

## Future

- [ ] iOS version (needs a Kotlin Multiplatform engine and a HealthKit source; see the iOS issue)
- [ ] Additional wearable sources
- [ ] More personalized models
- [ ] Community-contributed analysis modules
